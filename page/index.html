子代理工具

在已配置本地 MCP 的 Codex 项目中，可以查可用执行器、派单、查状态和收回执。工具通过本机进程的标准输入输出（stdio）连接，仅在配置了它的项目中提供。

授权与测试

  1. 按插件仓库的 README 下载对应版本并登记 Codex CLI 账号，然后运行 python3 runtime/executor_manager.py init 打开本机管理页。
  2. 选择执行账号和项目，完成只读探针并确认验收，再按 README 配置该项目的 MCP。
  3. 在该项目的新 Codex 会话里委派任务，之后用同一个任务 ID 查询状态和回执。

本页只提供使用指引。授权在管理页完成，派单和回执不经过 Magpie 网关。
